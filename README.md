# 프로젝트 소개 웹페이지

## 1. 프로젝트 제목

**프로젝트 소개 웹페이지**

## 2. 프로젝트 소개

간단하고 현대적인 프로젝트 소개 웹페이지입니다. 외부 라이브러리 없이 순수 HTML, CSS, JavaScript만으로 제작되었습니다.

이 웹페이지는 프로젝트를 소개하는 랜딩 페이지로 사용할 수 있습니다. 사용자가 버튼을 클릭하면 여러 가지 소개 문구가 순환되어 나타나며, 반응형 디자인으로 모바일에서도 깔끔하게 표시됩니다.

## 3. 주요 기능

- ✅ 상단에 큰 제목과 소개 문구 표시
- ✅ 버튼 클릭 시 5가지 다른 소개 문구 순환 변경
- ✅ 3개의 정보 카드 (반응형 그리드 레이아웃)
- ✅ 깔끔하고 현대적인 디자인
- ✅ 모바일/태블릿/데스크톱 반응형 디자인
- ✅ 호버 애니메이션 및 부드러운 전환 효과
- ✅ 키보드 접근성 지원 (Enter 키로 버튼 클릭)

## 4. 팀원 4명의 역할

| 팀원 | 역할 | 설명 |
|------|------|------|
| 팀원 A | 팀장, 기획 | 전체 프로젝트 방향 설정, 기획, 팀원 조율 |
| 팀원 B | 디자인 | 웹페이지 디자인, 색상 선정, 레이아웃 구성 |
| 팀원 C | 프론트엔드 | HTML 구조 작성, 스타일 적용 |
| 팀원 D | 프론트엔드 | JavaScript 기능 구현, 인터랙션 개발 |

## 5. 파일별 역할

| 파일명 | 역할 | 설명 |
|--------|------|------|
| **index.html** | 웹페이지 구조 | 웹페이지의 뼈대 역할입니다. 제목, 버튼, 카드 등 웹페이지에 표시될 내용을 정의합니다. |
| **style.css** | 디자인과 스타일 | 웹페이지의 꾸미기 역할입니다. 색상, 글자 크기, 레이아웃, 애니메이션 효과 등을 담당합니다. |
| **script.js** | 기능과 동작 | 웹페이지의 움직임을 담당합니다. 버튼 클릭 시 텍스트 변경, 카드 호버 효과 등을 처리합니다. |
| **README.md** | 프로젝트 문서 | 이 프로젝트에 대한 설명서입니다. 프로젝트 소개, 실행 방법, 파일 역할 등을 담고 있습니다. |

## 6. 웹사이트 실행 방법

### 방법 1: 파일을 브라우저에서 직접 열기 (가장 쉬움)
1. 파일 탐색기에서 `index.html` 파일을 더블 클릭합니다.
2. 기본 브라우저(Chrome, Edge, Safari 등)에서 웹페이지가 열립니다.

### 방법 2: VS Code 라이브 서버 사용 (추천)
1. VS Code에서 **Live Server** 확장 프로그램을 설치합니다.
2. `index.html` 파일을 열고 마우스 오른쪽 버튼을 클릭합니다.
3. **"Open with Live Server"**를 선택합니다.
4. 코드를 수정하면 자동으로 브라우저가 새로고침됩니다.

### 방법 3: Python 로컬 서버 사용
터미널에서 다음 명령어를 입력합니다:
```bash
python -m http.server 8000
```
그 후 브라우저에서 `http://localhost:8000`으로 접속합니다.
