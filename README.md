# 프로젝트 소개 웹페이지

## 1. 프로젝트 제목

**프로젝트 소개 웹페이지**

## 2. 프로젝트 소개
## 1. 프로젝트명

맞춤형 여행 코스 추천 및 여행 데이터 공유 사이트

## 2. 프로젝트 소개

본 프로젝트는 여행 계획을 세우는 것을 번거롭게 느끼는 사용자를 위해 맞춤형 여행 코스를 추천하는 웹사이트를 제작하는 것을 목표로 한다. 사용자가 출발지, 여행지, 인원수, 교통수단, 여행 기간, 예산, 선호하는 여행 스타일 등을 입력하면 실제 이동 시간과 동선을 고려하여 현실적으로 실행할 수 있는 여행 코스를 제공한다.

기존 여행 추천 서비스가 유명 관광지를 단순히 나열하는 방식이라면, 본 프로젝트는 실제 여행자들이 제공한 이동 경로, 방문 순서, 사용 비용, 후기 등의 데이터를 축적하여 사용자와 조건이 비슷한 여행 사례를 바탕으로 코스를 추천하는 것을 핵심으로 한다.

또한 여행을 다녀온 사용자가 자신의 여행 기록과 비용, 사진, 후기를 제공하면 보상을 받을 수 있도록 구성한다. 데이터가 부족한 지역이나 대중교통 여행, 반려동물 동반 여행처럼 사례가 적은 조건에는 더 높은 보상을 제공하여 다양한 여행 데이터를 확보하고자 한다.

## 3. 주요 기능

* 출발지, 목적지, 인원수, 교통수단 입력
* 여행 기간, 예산, 선호 여행 스타일 입력
* 이동 시간과 동선을 고려한 여행 코스 추천
* 기존 여행자의 실제 여행 기록 활용
* 여행 후기와 이동 경로 데이터 등록
* 데이터 제공자에게 여행지원금 또는 포인트 등의 보상 제공
* 숙박업체, 음식점, 카페 등의 무료 업체 등록

## 6. 웹사이트 실행 방법

### 방법 1: 파일을 브라우저에서 직접 열기 (가장 쉬움)
1. 파일 탐색기에서 `index.html` 파일을 더블 클릭합니다.
2. 기본 브라우저(Chrome, Edge, Safari 등)에서 웹페이지가 열립니다.

### 방법 2: VS Code 라이브 서버 사용 (추천)
1. VS Code에서 **Live Server** 확장 프로그램을 설치합니다.
2. `index.html` 파일을 열고 마우스 오른쪽 버튼을 클릭합니다.
3. **"Open with Live Server"**를 선택합니다.
4. 코드를 수정하면 자동으로 브라우저가 새로고침됩니다.

### 방법 3: Python 로컬 서버 사용
터미널에서 다음 명령어를 입력합니다:
```bash
python -m http.server 8000
```
그 후 브라우저에서 `http://localhost:8000`으로 접속합니다.
