계획은 우리가 짤게요. 여러분은 그냥 떠나세요.

출발지, 인원, 교통수단과 여행 성향만 입력하면 실제 여행 데이터를 바탕으로 맞춤 여행 코스를 추천해드립니다.

서비스 이용 방법

1

여행 조건 입력

출발지, 목적지, 인원수, 교통수단 등 여행 조건을 입력하세요.

2

비슷한 실제 여행 데이터 분석

실제 여행자들의 비슷한 여행 데이터를 찾아 분석합니다.

3

맞춤형 여행 일정 확인

분석된 데이터를 바탕으로 최적의 여행 코스를 추천해드립니다.
